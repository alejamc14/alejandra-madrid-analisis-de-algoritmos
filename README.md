# Curso de Análisis de Algoritmos

Repositorio correspondiente al curso de Análisis de Algoritmos. Este repositorio será utilizado durante todo el semestre para organizar los cinco informes de laboratorio evaluativos y las actividades desarrolladas durante el curso.

## Estructura del repositorio

El repositorio está organizado de la siguiente manera:

- **`laboratorios/`**: contiene los cinco informes de laboratorio evaluativos desarrollados durante el semestre.
- **`ejercicios-clase/`**: contiene los ejercicios realizados durante las sesiones de clase.
- **`benchmarks/`**: contiene los archivos relacionados con los benchmarks realizados durante el curso.
- **`README.md`**: contiene la descripción y documentación general del repositorio.
- **`.gitignore`**: contiene las reglas para indicar a Git qué archivos o directorios deben ser ignorados.

La estructura general del repositorio es:

```text
curso-analisis-algoritmos/
├── laboratorios/
├── ejercicios-clase/
├── benchmarks/
├── README.md
└── .gitignore
```
**Nota de Configuración:**

Se ha añadido un archivo `.gitkeep` en las carpetas vacías para poder incluir y mantener la estructura del proyecto en el repositorio de Git, ya que este sistema no rastrea directorios que no contienen archivos. 

## Control de versiones

El repositorio utiliza Git para registrar los cambios realizados durante el desarrollo de las actividades y GitHub para sincronizar el trabajo mediante el repositorio remoto.

Los cambios realizados pueden consultarse mediante el siguiente comando:

```bash
git log --oneline
```

Los avances significativos del repositorio se registrarán mediante commits descriptivos y se sincronizarán con GitHub utilizando `git push`.
